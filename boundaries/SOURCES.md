# Boundary sources

These files are release-candidate administrative boundaries, not an assertion of legal sovereignty or maritime jurisdiction.

- `ID.geojson`: geoBoundaries gbOpen Indonesia ADM0, boundary ID `IDN-ADM0-11942859`, 2017 representation, Open Data Commons Open Database License 1.0; source lineage: OpenStreetMap / Wambacher.
- `VN.geojson`: geoBoundaries gbOpen Viet Nam ADM0, boundary ID `VNM-ADM0-46766057`, 2016 representation, CC BY 4.0; source lineage: geoBoundaries / Wikimedia Commons.

The exact downloaded files are pinned by SHA-256 in the country profiles. A signed release must retain this attribution and be reviewed against the authority-approved boundary policy before publication.
